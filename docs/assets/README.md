The full-size hero preserves the approved image's pixels and dimensions. The README uses a smaller export for loading speed. Each section illustration retains its full generated resolution.

Use the 1280 × 640 PNG for GitHub's repository social preview. It is optimized to stay under the 1 MB upload limit. [GitHub's requirements](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Visual direction

The illustrations use ivory paper, cobalt enamel joints and vermilion cloth bindings. The hero's ADEPTORY wordmark uses a high-contrast editorial serif. Keep that lettering with the artwork.

The build-flow diagram uses the same palette and provides labels for the workflow described in the README. Its SVG includes a title and description. The README also includes the steps as text.

[Section-art prompts](art-prompts.txt) record the prompts used with the approved hero as the reference image.
